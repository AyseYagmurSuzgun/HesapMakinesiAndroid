# 📱 Android Hesap Makinesi Uygulaması

Bu proje, Android Studio kullanılarak **Kotlin** dili ile geliştirilmiş basit bir **hesap makinesi uygulamasıdır**.  
Uygulama, temel matematiksel işlemleri kullanıcı dostu bir arayüz ile gerçekleştirmeyi amaçlamaktadır.

---

## ✨ Özellikler
- ➕ Toplama
- ➖ Çıkarma
- ✖️ Çarpma
- ➗ Bölme
- 🔢 Ondalıklı sayılar
- 🔁 Parantez kullanımı
- 🧹 AC (Tümünü temizle)
- ⌫ DEL (Son karakteri sil)

---

## 🛠 Kullanılan Teknolojiler
- **Kotlin**
- **Android Studio**
- **XML (UI tasarımı)**
- **ConstraintLayout & LinearLayout**
- **TableLayout**
- **exp4j** (matematiksel ifadelerin hesaplanması için)
